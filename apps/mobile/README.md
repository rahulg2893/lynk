# Lynk for iPhone and Android

One Expo app (SDK 57, React Native 0.86, Expo Router, React Compiler) with every feature of the web app, on the same sample data. There is no backend yet.

## Run it

You need Xcode for iPhone or Android Studio for Android. Lynk uses native modules (SQLCipher, secure storage, audio), so it runs as a development build, not in Expo Go.

```bash
npm install             # also applies patches/ through patch-package
npx expo run:ios        # builds, installs on the simulator and starts Metro
npx expo run:android
```

Sign in with **+91 98765 43210** and any 6 digits.

After the first build, `npx expo start` is enough to start Metro. If an edit inside `src/app/(tabs)/` doesn't show up, restart it with `npx expo start --clear`, or install Watchman (`brew install watchman`).

## How it's put together

- **Routes** live in `src/app` (Expo Router). The tabs are native tabs: Chats, Catch up, Calendar, Saved and You.
- **Shared logic** comes from the web app: `@shared/*` points at `../web/src/lib` (see `tsconfig.json` and the `watchFolders` entry in `metro.config.js`). Plan spotting, search, notification grouping, calendar export and the phone-number rules are the same code on both apps.
- **Storage** is an encrypted SQLCipher database (`src/lib/storage.ts`). Its key is random and kept in the iOS Keychain or Android Keystore, on this device only.
- **Chat state** lives in `src/lib/store.ts`: sending, the offline outbox, simulated replies, plans, to-dos and lists.

## Build fixes you might hit

- **iOS 27 requires the scene lifecycle.** `plugins/with-scene-lifecycle.js` adds it during prebuild.
- **Paths with spaces.** Two build scripts broke on a space in the project path. `plugins/with-quoted-bundle-script.js` and `patches/expo-constants+*.patch` fix them.
- **CocoaPods encoding errors.** Run `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8` before building.

The `ios/` and `android/` folders are generated by `expo prebuild` and are not committed. Change native settings in `app.json` or a config plugin.

## Test

A [Maestro](https://maestro.dev) flow signs in, opens a group, sends "Dinner Friday 8pm at Nando's?", checks the plan suggestion, opens Up next, asks Lynk a question and visits every tab:

```bash
maestro test .maestro/smoke.yaml
```

Also run `npx tsc --noEmit` and `npx expo lint` before committing.
